# 카멜레온 숨바꼭질

몸에 직접 색을 칠해 집 안 배경에 숨는 3D 숨바꼭질 게임. 술래 3명이 총을 들고 찾아다닙니다.

`index.html` 하나로 돌아가요. 브라우저로 열면 바로 플레이할 수 있어요 (PC·모바일 모두 지원).

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 (살짝 밀면 살금살금) |
| 시점 | 마우스 드래그, Q/E | 화면 드래그 |
| 줌 | 마우스 휠 | 두 손가락 핀치 |
| 점프 | Space | 점프 버튼 |
| 몸에 칠하기 | C | 그리기 버튼 |
| 스포이드 | P | 스포이드 버튼 |
| 포즈 | T, 1·2·3 | 포즈 버튼 |
| 제자리 고정 | R | 고정 버튼 |
| 일시정지 | Esc | ⏸ 버튼 |
